## Keybinds

Plasma ships with its own default shortcuts (meta to open the application launcher, and so on). Check or customize them in System Settings -> Shortcuts.

f12 -> toggle Yakuake (drop-down terminal)

## Plasma tweaks

Panel, widgets, wallpaper and theme can all be changed from System Settings.
