## Hello

Thank you for trying d77void Helium edition.

Helium ISO uses NIRI as WC and the rust custom shell Helium-d77.

To install use Calamares. Call it with "install system" from the menu.

## Keybinds

Super + t -> terminal

Super + shift + e -> logout

Super + o -> gmrun

Super + q -> close window

Super + Space -> apps menu

Super + x -> powermenu

Super + y -> wallpaper picker

Super + Alt + l -> lock screen

Have fun!
