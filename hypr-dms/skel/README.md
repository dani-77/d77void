## Hello

Thank you for trying d77void Hyprland DMS edition.

This ISO uses Hyprland together with DankMaterialShell (dms) as the shell.

To install use Calamares from the menu.

## Keybinds

super + t -> terminal

super + space -> app launcher

super + comma -> settings

super + n -> notifications

super + shift + n -> notepad

super + v -> clipboard

super + m -> task manager

super + o -> gmrun

super + y -> wallpaper picker

super + tab -> overview

super + x -> powermenu

super + alt + l -> lock screen

super + shift + e -> logout

super + q -> close window

super + shift + / -> keybinds cheat sheet

## Hyprland tweaks

To alter the autostart programs, add/swap keybinds and keyboard layout configure ~/.config/hypr/hyprland.conf and the files inside ~/.config/hypr/dms/ ; the files are self explanatory and with several examples already configured.

Have fun!
