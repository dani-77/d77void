## Keybinds

super -> launcher

super + t -> terminal

super + b -> web browser

super + f -> home folder

super + w -> workspace overview

super + q -> close window

super + escape -> lock screen

super + shift + escape -> logout

print -> screenshot

## COSMIC tweaks

Keybinds, panel, dock, wallpaper and theme can all be changed from the COSMIC Settings app.
