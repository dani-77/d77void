## Hello

Thank you for trying d77void niri Noctalia edition.

This ISO uses niri together with the Noctalia shell.

To install use Calamares from the menu.

## Keybinds

super + t -> terminal

super + space -> launcher

super + comma -> settings

super + alt + l -> lock screen

super + n -> clipboard

super + x -> session menu

super + y -> wallpaper picker

super + shift + e -> logout

super + q -> close window

super + d -> toggle overview

## niri tweaks

To alter the autostart programs, add/swap keybinds and keyboard layout configure ~/.config/niri/config.kdl and the files inside ~/.config/niri/noctalia/ ; the files are self explanatory and with several examples already configured.

Have fun!
