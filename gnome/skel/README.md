## Hello

Thank you for trying d77void GNOME edition.

This edition ships with the PaperWM extension enabled, turning GNOME into a scrollable tiling window manager. If you prefer the classic GNOME workflow, disable it from the Extensions app.

To install use Calamares from the menu.

## Keybinds

super -> activities overview

Default GNOME shortcuts apply; check or customize them in Settings -> Keyboard -> Keyboard Shortcuts. PaperWM's own bindings can be found in its extension preferences.

## GNOME tweaks

Extensions (dash-to-dock, blur-my-shell, PaperWM and others) can be toggled and configured from the Extensions app.

Have fun!
