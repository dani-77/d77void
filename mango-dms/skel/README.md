## Hello

Thank you for trying d77void Mango DMS edition.

This ISO uses MangoWC together with DankMaterialShell (dms) as the shell.

To install use Calamares from the menu.

## Keybinds

super + t -> terminal

super + space -> app launcher

super + comma -> settings

super + n -> notifications

super + shift + n -> notepad

super + v -> clipboard

super + m -> task manager

super + y -> wallpaper picker

super + x -> powermenu

super + alt + l -> lock screen

super + q -> close window

alt + m -> quit mango

## Mango tweaks

To alter the autostart programs, add/swap keybinds and keyboard layout configure ~/.config/mango/config.conf and the files inside ~/.config/mango/dms/ ; the files are self explanatory and with several examples already configured.

Have fun!
