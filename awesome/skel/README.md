## Keybinds

super + return -> terminal

super + a -> menu

super + b -> swap wallpaper

super + c -> toggle calendar

super + s -> display keybinds

super + t -> lock screen

super + w -> menu (this is the main awesome menu)

super + r -> run

super + z -> powermenu
